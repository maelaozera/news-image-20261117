A newspaper front page summing up Tuesday 17 November 2026: the Kerch Bridge
strike, tankers hit near Hormuz, Trump in Manila, the JPMorgan banking outage,
the Vulcan rocket failure that destroyed 40 Amazon satellites, and Depardieu's
guilty plea in Paris.

`main.ts` copies the bundled `entry.png` (1024x1024, under 1 MiB) to the
output directory. Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
